# GPX/KML Track Files

Put verified route files here when they are available from the guide, GPS watch, Komoot, Gaia GPS, AllTrails, Outdooractive, or exported Google Earth routes.

Recommended naming:

- `day-01-rosengarten.gpx`
- `day-02-marmolada.gpx`
- `day-03-seceda.gpx`
- `day-04-alpe-siusi.gpx`
- `day-05-cinque-torri.gpx`
- `day-06-tre-cime.gpx`

Verified GPX files are configured as each route's default track and loaded automatically. The app does not expose manual upload or reset controls.

Built-in verified tracks currently included:

- `day-01-rosengarten.gpx` - Outdooractive, Geotrail 9 to Karersee/Carezza via Kuregg/Monte Coronelle. Original KML is also stored as `day-01-rosengarten.kml`.
- `day-02-alba-viel-sass-pordoi.gpx` - Outdooractive에서 직접 제작한 A/B 통합 트랙. Alba → Fredarola 공통 구간, B팀 Viel dal Pan 왕복, Passo Pordoi → Sass Pordoi 구간을 포함하며 현재 앱에서 사용한다.
- `day-02-alba-viel-dal-pan.gpx` - 이전에 직접 제작한 Alba → Col dei Rossi → Fredarola → Viel dal Pan 편도 트랙. 현재 앱에는 표시하지 않는다.
- `day-02-viel-dal-pan.gpx` - 이전에 사용한 Ammappalitalia Passo Pordoi → Rifugio Viel dal Pan 참고 트랙. 현재 앱에는 표시하지 않는다.
- `day-05-scoiattoli-averau.gpx` - 5 Torri, Scoiattoli to Averau segment.
- `day-06-tre-cime.gpx` - Trecime Trek, full Tre Cime di Lavaredo circuit.
